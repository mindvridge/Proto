## 🎨 프롬프트 사용 팁

### Niji6 파라미터
- `--style expressive`: 역동적이고 표현력 있는 스타일
- `--style cute`: 귀여운 치비 스타일
- `--style scenic`: 풍경/배경용
- `--ar 1:1`: 정사각형 (아이콘용)
- `--ar 3:4`: 캐릭터 초상화
- `--ar 16:9`: 배경/씬
- `--ar 9:16`: 모바일 세로 UI

### V7 파라미터
- `--q 2`: 최고 품질
- `--ar 3:4`: 캐릭터
- `--ar 16:9`: 배경
- `--ar 1:1`: 아이템 아이콘
- `--style raw`: 더 사실적인 결과

### 공통 키워드
- **게임 아트**: "game character art", "mobile game design", "RPG illustration"
- **웹툰 스타일**: "webtoon style", "Korean manhwa", "clean lineart"
- **품질**: "professional", "detailed", "high quality", "4K"
- **배경**: "white background" (아이콘), "transparent background" (UI)
