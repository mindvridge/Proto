## 1. 프로젝트 개요

### 1.1 프로젝트 정보

```
프로젝트명: 숨겨진 성장의 백수 영웅
영문명: Hidden Growth NEET Hero
장르: 싱글플레이 클리커 RPG (방치형)
플랫폼: Android, iOS
타겟: 캐주얼 게이머, 20~40대
개발 엔진: Unity 2020.3 LTS 이상
예상 개발 기간: 8~12개월
예상 팀 규모: 2~4명
```

### 1.2 핵심 목표

```
✅ MVP (Minimum Viable Product) 6개월 내 완성
✅ 소프트 런칭으로 시장 검증
✅ 안정적인 수익 모델 확립
✅ DAU 10,000+ 목표
✅ 리텐션 D1 40%, D7 20%, D30 10%
```

### 1.3 예산 및 수익 목표

```
개발 예산: $5,000~10,000
- Unity 라이선스: $0 (Personal 무료)
- Firebase: $0~100/월
- 아트 에셋: $500~1,000
- 사운드/음악: $300~500
- 광고/마케팅: $2,000~5,000

수익 목표:
- 1개월: $500 (손익분기)
- 3개월: $2,000
- 6개월: $5,000
- 12개월: $10,000+
```
