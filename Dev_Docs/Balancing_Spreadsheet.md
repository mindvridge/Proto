## 🔄 환생 시스템

### 환생 포인트 계산 공식
```
RebirthPoints = (TotalGold × 0.001) + (Level × 100) + (ClearedDungeons × 500) + (Achievements × 200)
Penalty = 1.0 - (RebirthCount / 10 × 0.1)  // 최소 0.5
FinalPoints = BasePoints × Max(Penalty, 0.5)
```
